📋 Power BI Embed Not Configured

To enable the embedded Power BI report, set the following environment variables in dashboard/.env and redeploy:

VariableDescription
POWERBI_EMBED_ENABLED Set to true to show the embedded report on this page
POWERBI_REPORT_URL Power BI embed URL — copy from Share → Embed report → Website or portal
POWERBI_WORKSPACE_ID Fabric workspace GUID (shown in the Power BI URL)
POWERBI_REPORT_ID Report GUID (shown in the Power BI URL)

See fabric/README.md for step-by-step instructions to create the Fabric workspace, Eventhouse, Eventstream, and publish the Power BI template.

🔗 Data Pipeline Architecture

The same IoT Hub that feeds the edge dashboard also feeds the Fabric analytics layer. The AIO Dataflow anonymises telemetry before export — GPS is rounded, altitude and device metadata are stripped.

[Azure Local — Field] [Azure Cloud — Office] Drone Simulator Microsoft Fabric Workspace → AIO MQTT ← IoT Hub Eventstream → IoT Hub ──────────────────→ Eventhouse (KQL DB) ↓ AIO Dataflow rounds GPS Power BI Report to ~1.1 km, strips altitude (this page, when configured)
